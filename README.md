## Разработка и запуск продукта

Я веб-разработчик с образованием в области кибербезопасности. Беру коммерческие проекты целиком: требования → архитектура → разработка → интеграции → деплой → сопровождение. Работаю с реальными заказчиками, а не только с учебными задачами.

- **Разработка приложений:** Next.js (App Router), React, серверные компоненты и API-роуты, типизация на TypeScript, поддерживаемая структура проекта.
- **Интерфейсы:** адаптивная вёрстка на Tailwind CSS, скорость загрузки, корректная работа с телефона, аккуратная типографика и состояния.
- **Данные:** проектирование схемы, миграции, политики доступа к строкам, типизированные запросы — PostgreSQL / Supabase и libSQL / Turso.
- **Интеграции и автоматизация:** WhatsApp Cloud API (прямое подключение к Meta, без посредников), вебхуки, формы заявок, уведомления, админ-панели, роли и разграничение доступа.
- **Доставка:** деплой на Vercel, домены и переменные окружения, CI на GitHub Actions, правки и поддержка после сдачи проекта.

Магистратура по программной инженерии — **КБТУ, Алматы** *(в процессе)*. Бакалавриат по кибербезопасности — **Astana IT University** *(окончен)*. Коммерческая веб-разработка на фрилансе — **с 2025 года**.

### Aliari IT Service — приём заявок через WhatsApp и панель для сотрудников

Рабочая система для IT-компании: бот принимает заявки прямо в WhatsApp по сценарию (тип клиента → формат помощи → адрес и время с проверкой рабочего графика → контакты → подтверждение), заявке присваивается номер, переписка клиента сохраняется и привязывается к его активной заявке. Внутри — панель для 7 сотрудников, задачи и маршруты от руководителя, база клиентов и простая аналитика. Подключение к **WhatsApp Cloud API напрямую от Meta**, без сторонних шлюзов — у заказчика нет абонплаты посреднику. Задеплоено и проверено end-to-end.

## Как я работаю

1. **Разбираем задачу.** Что нужно, для кого, по какому результату поймём, что получилось.
2. **Быстрый рабочий прототип.** Не картинка, а версия, которую можно открыть и потыкать.
3. **Итерации по вашим правкам.** Правим, пока не сойдётся — два круга правок входят в работу.
4. **Деплой и передача.** Выкладываю на хостинг, подключаю домен, отдаю доступы, остаюсь на связи.

AI-ассистированную разработку (Claude Code, Cursor) использую как основной рабочий процесс — за счёт этого срок от задачи до рабочей версии заметно короче. Но весь код читаю, правлю и тестирую сам: заказчик получает работающий продукт, а не сгенерированный текст. Говорю об этом открыто, потому что для клиента это выигрыш по срокам, а не то, что стоит прятать.
