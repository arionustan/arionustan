## Как я работаю

Использую AI-ассистированную разработку (Claude Code, Cursor) как основной рабочий процесс — это заметно сокращает срок от идеи до рабочей версии. Но код всегда проверяю и тестирую сам: клиент получает работающий результат, а не сгенерированный текст.

1. **Обсуждаем задачу** — что нужно, для кого, какой результат считается успешным
2. **Прототип быстро** — первая рабочая версия, которую можно посмотреть и потрогать
3. **Итерации** — правим по вашим комментариям, пока не сойдётся
4. **Деплой** — выкладываю на хостинг, подключаю домен, передаю доступы
